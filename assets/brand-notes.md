# Tradefloor identity

The mark combines an architectural T/F monogram with a brass floor line. The structure
suggests an exchange floor, a ledger and a framework for competing views. It carries no
price, probability or upward-only promise.

- `logo.svg`: ink wordmark for light backgrounds.
- `logo-dark.svg`: light wordmark for dark backgrounds.
- `logo-mark.svg`: compact symbol for icons and avatars.

Palette: ink `#10232e`, off-white `#f0f3ef`, brass `#b99b68`, muted slate `#61717a`.
Use the dark variant on dark surfaces. Preserve proportions and clear space; do not
stretch, rotate or add shadows. SVG assets have no external font or image dependencies;
the wordmark uses the system Arial/Helvetica stack.
